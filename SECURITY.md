# Security policy

## Supported versions

| Version | Supported |
|---|---|
| 0.1.x | Yes |

## Reporting a vulnerability

Please report vulnerabilities privately through **GitHub private vulnerability reporting**: the
repository's **Security** tab, then **Report a vulnerability**. Do not open a public issue.

The threat model is described in [SECURITY-MODEL.md](SECURITY-MODEL.md): what is trusted, what
`confirm` does and does not guarantee, and how redaction works.
