# mcp-patchbay

Let your AI agent switch MCP servers on and off in the middle of a session.

mcp-patchbay is one MCP server that hosts your other MCP servers. The agent can list them, start one
when a task needs it and stop it afterwards. The started server's tools appear and disappear
straight away, with no restart. Turning on a server that is off by default asks a person first.

It is under construction. The first version is being built now, so nothing here is ready to install
yet.
